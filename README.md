## 엔딩
판정 순서: SECRET → 최종 행동 → 수치

게임 화면에는 TRUE·BAD 같은 등급 없이 『이름』만 나옵니다(v1.5). 아래 표의 구분 이름(코드 id)은 제작용입니다.

| 엔딩 (코드 id) | 조건 | 타이틀에 남는 흔적 |
|---|---|---|
| 『식탁의 주인』 (secret) | DAY 7에 급식실에 들어가기 전, 지하 예배당 제단을 직접 조사. memory 100, cult_truth 100 (선택 요소를 전부 모아야 함) | 접시는 하나뿐이었다. |
| 『포식자』 (bad1) | 마지막 식탁에서 '유리를 먹는다' (yuri_sync 80 이상, '남겨도 돼'를 고르지 않았을 때만 나옴) | 입을 열지 않았다. |
| 『피식자』 (bad2) | '유리에게 먹힌다' (yuri_sync 50 이상, momo_trust 30 미만, '남겨도 돼'를 고르지 않았을 때만 나옴) | 남김없이. |
| 『나와 너의 사이』 (true) | '식탁에서 일어난다' + memory 80, cult_truth 80, momo_trust 60 이상. 시계가 8시 14분이 되는 건 이 결말뿐 | 째깍. |
| 『두 사람 몫의 식탁』 (normal) | '식탁에서 일어난다' + 위 조건 미달 | "늦었네." |

마지막 식탁의 질문 네 가지(너는 나를 사랑했어 / 왜 나를 먹었어 / 나는 네 안에 있었어 / 이제 그만하고 싶어)는 원하는 순서로 한 번씩 물을 수 있고 수치는 바뀌지 않습니다. DAY 5에 '처음 같이 먹은 날'을 봤으면 '남겨도 돼.'가 생기고, 고르면 질문이 끝나며 『포식자』『피식자』가 빠집니다.

- 엔딩을 하나라도 보면 타이틀 음악이 바뀌고, 제목 아래에 **마지막으로 본 엔딩의 한 줄**이 남습니다. 어느 엔딩을 봤느냐에 따라 다른 흔적이 남습니다.
- 엔딩을 하나라도 보면 타이틀에 RECORD(회차 기록부)가 생깁니다. 아래 '회차 기록부' 참고.
- SECRET END를 본 뒤에는 타이틀에 EAT이 생깁니다. 고르면 같은 이름·성별로 처음부터 다시 시작합니다.
- DAY 7 아침에 자동 저장되므로 '이어 하기'로 마지막 식탁을 다시 고를 수 있습니다.

## 화면 구성 (v0.4)
- 남색 패널에 옅은 이중 테두리와 모서리 마름모 장식. 선택된 항목은 크림색 띠에 금색 표시.
- 왼쪽 위에 `DAY n / AM 08:13`이 표시됩니다. 시계는 저녁에도 밤에도 08:13입니다.
- 대사창: 왼쪽에 액자형 얼굴 칸(144×144), 그 오른쪽에 이름과 밑줄, 본문 3줄.
- 메뉴(오른쪽 위 MENU 또는 X/Esc): 왼쪽 명령 패널(아이템·저장·소리·타이틀로·닫기)과 오른쪽 INVENTORY 창(6×2 칸 + 종이 질감 설명란).
- 타이틀: NEW GAME / CONTINUE / LOAD / ENDINGS / RECORD(엔딩을 본 뒤) / OPTION(소리 켜기·끄기) / EAT(식탁의 주인을 본 뒤). 제목 글자와 메뉴는 게임이 위에 그리므로, `cg_title.png`는 글자 없이 그리고 가운데(x 278~538, y 300~456)를 비워 두면 좋습니다.
- 문서 보기: 교리책·요리책·졸업앨범은 펼친 책, 출석부·양호실 기록부는 장부, 찢어진 편지·게시판은 종이로 보여 줍니다. 결정 키나 오른쪽 탭으로 다음 장, ← 키나 왼쪽 탭으로 이전 장. 전부 코드로 그리므로 따로 그릴 그림은 없습니다.
- 글꼴은 Noto Sans KR / Noto Serif KR(Google Fonts)을 불러오고, 오프라인이면 기기 기본 글꼴을 씁니다.

- 주소 끝에 `?debug`를 붙이거나 F2를 누르면 오른쪽 위에 변수(memory, yuri_sync, momo_trust, cult_truth)가 표시됩니다.

## 조작
| 동작 | 키보드 | 터치·마우스 |
|---|---|---|
| 이동 | 방향키 / WASD | 가고 싶은 칸을 탭 |
| 조사·대화·결정 | Z / Enter / Space | 대상을 탭 (멀면 걸어가서 조사) |
| 메뉴 | X / Esc | 오른쪽 위 ≡ 버튼 |
| 소리 켜기/끄기 | N | 메뉴 |
| 읽은 대사 빨리 넘기기 | C 또는 Tab으로 켜고 끄기 / Ctrl 누르는 동안 | 대사 중 오른쪽 위 SKIP 버튼 |

**휴대폰·태블릿(터치 기기)**
- 화면 왼쪽 아래에 방향키, 오른쪽 아래에 결정·메뉴 버튼이 나옵니다. 가로로 들면 게임 화면 양옆의 빈 자리에 놓입니다. 방향키는 누르고 있으면 계속 걷고, 짧게 누르면 돌아보기만 합니다.
- 화면 탭 조작(칸을 탭해서 이동·조사)도 그대로 쓸 수 있습니다.
- 세로로 들고 있으면 ‘휴대폰을 가로로 돌려 주세요’ 안내가 나옵니다. ‘세로로 계속하기’를 누르면 그 탭을 닫을 때까지 다시 나오지 않습니다.
- 마우스·키보드 기기에서는 방향키와 안내가 나오지 않습니다.

이동은 RPG Maker 기본 속도(한 칸 약 0.27초)입니다. 멈춰 있을 때 다른 방향키를 짧게 누르면 그 방향으로 돌아보기만 하고, 계속 누르고 있으면 걷기 시작합니다. 걷는 중에는 방향을 바꿔도 끊기지 않습니다. 걸음은 한 칸마다 왼발·오른발을 번갈아 내딛습니다(도트 시트의 0열·2열).

타이틀의 ENDINGS에서 본 엔딩과 엔딩 CG를 다시 볼 수 있습니다. 아직 못 본 엔딩은 이름이 가려지고 힌트가 나옵니다.

## 은신 · 추격 (v2.0)
기획서 v3.0 10장. 지하의 실패체(‘아직 끝나지 않은 사람들’)가 주인공을 쫓습니다. 코드는 `js/chase.js`.

- **숨기**: 바닥에 점선으로 표시된 칸(서가 사이, 식탁 아래)에 멈춰 있으면 보이지 않습니다. 다만 숨는 모습을 들키면 그 칸을 뒤집니다.
- **달리기**: 쫓기는 동안에는 저절로 뜁니다. 평소에는 Shift를 누르고 있으면 뛰지만 발소리가 나서 근처의 적이 조사하러 옵니다.
- **적의 상태**: 순찰 → (소리) 조사 → 수색 → (보이면) 추격 → 놓치면 수색 후 순찰. 서가·벽·식탁 너머는 보지 못합니다. 몸의 여러 부분이 잠깐 같은 방향을 고를 때 빨라집니다(심장 소리).
- **붙잡히면** 체크포인트로 돌아갑니다. 점수는 깎이지 않고 결말에도 영향이 없습니다. 연속 3번 붙잡히면 ‘추격 완화’(적이 덜 멀리 보고 더 느림)를 고를 수 있습니다.
- **DAY 3 지하 기록실**: 철문 너머 목소리 → 모모와 서가 사이에 숨기 → 맨 아래 안쪽 기록실의 출석부 → 그림자(눈·손가락)가 위쪽 서가를 순찰 → 사다리까지. 체크포인트: 지하 도착, 출석부를 집은 직후.
- **DAY 6 지하 예배당**: 아래층(서가)으로 들어와 위층 식탁의 이름 접시 → 기록함(모모가 레버 A를 잡고, 내가 레버 B로 복도 철문을 닫아야 열림) → 기록·색인표·모모의 접시 → 철문이 들려 실패체가 들어옴 → 식탁 아래 숨기 → 아래층 → 금속 식판을 던져 옆방으로 유인 → 레버 C로 옆방 철문을 닫아 가둠 → 오른쪽 작은 방의 빈 도시락 → 철문이 부서지고 출구까지 짧은 추격. 체크포인트: 기록함을 연 뒤, 아래층에 들어설 때, 옆방에 가둔 뒤, 빈 도시락을 얻은 뒤.
- 그림: `assets/characters/monster_shadow.png`(DAY 3), `monster_union.png`(DAY 6)를 넣으면 그 그림을 씁니다(한 장, 발끝이 그림 아래 가운데). 없으면 코드로 그린 실루엣이 나옵니다.

## 캐릭터 도트 (v3.2)
- 주인공(남·여)·유리·모모·이안·선생님은 보내준 큰 참고 시트를 `tools/import_sprites.py`로 48×48 걷기 시트로 다시 만들었습니다(설정: `tools/import_sprites_cfg.json`).
  - 모두 키를 43px로 맞춰 머리 크기를 통일(학생 4명과도 같은 크기). 시트는 다시 144×192.
  - 줄일 때 칸마다 원본 색을 세어 어두운 선·포인트 색(금장·리본·핀)·하이라이트를 우선 → 테두리와 장식이 뭉개지지 않음.
  - 얼굴(눈·입·핀)은 `tools/faces.json`에 캐릭터·방향별로 좌표를 정해 찍습니다(v3.3). 걸음 칸은 머리가 움직인 만큼 자동으로 옮겨 찍습니다.
    - 눈 무늬(`faces.json`의 patterns): 주인공·모모 둥근 눈(속눈썹이 앞머리 끝선에 닿게), 유리도 주인공·모모와 같은 둥근 눈(보라 눈동자, v3.7), 이안 안경(테 안에 눈, 두 눈 간격을 넓힘, 옆모습은 안경다리), 선생님 여우상 실눈(눈꼬리가 바깥 위로 올라간 사선, 두 눈 사이 3칸) + 볼터치 + 웃는 입, 옆모습도 같은 사선 실눈(v3.5).
    - 모모: 오른쪽 눈은 앞머리에 가려 있어 정면은 왼쪽 눈만, 오른쪽을 볼 때는 눈 없이 앞머리만. X 핀은 세 방향 같은 모양.
    - 얼굴을 고치려면 `faces.json` 좌표만 바꾸고 `python3 tools/import_sprites.py tools/import_sprites_cfg.json <출력>`.
  - 발끝 y45 맞춤, 걸음 칸 좌우 흔들림 제거는 `tools/clean_sprites.py`와 같은 방식.
- 서 있는 칸(가운데 열, 멈춰 있을 때 쓰는 그림): 원본은 한 발을 든 걷는 도중 그림이라 `tools/stand_pose.py`로 고침(v3.8). 정면·뒷모습은 땅을 딛은 다리를 좌우 반전해 두 발을 가지런히, 목 아래 몸통도 몸에 붙은 팔 쪽으로 좌우 대칭(팔을 흔들지 않게), 옆모습은 보폭이 벌어진 경우 몸 중심 쪽 발만 남기고 뒤로 1칸 어두운 다리를 덧그림. import/clean 스크립트가 마지막에 자동 적용.
- 일반 학생 4명(v4.0, `tools/make_students.py`): 학생1 = 이안 머리 모양(안경 없는 바탕 `tools/base_ian_plain.png`) 갈색 / 학생2 = 여주의 일자 앞머리·턱선 머리 + 남주 몸, 밝은 갈색 / 학생3 = 검은 단발(여주 머리 턱선 컷 + 모모 몸) / 학생4 = 긴 밝은 갈색(여주). 눈은 하이라이트 없는 회갈색.
- 남주·남학생 서 있는 다리: 두 다리를 붙이고 가운데 1칸 검은 선, 몸통 중앙 기준 좌우 대칭(v4.0, `stand_pose.py` style=join). 다른 캐릭터는 다리 사이 1칸 틈.
- 유리·이안: 얼굴 폭을 다른 캐릭터(10칸)에 맞추려 키 47px로 키움 → 칸 48×56(시트 144×224), 엔진이 발끝 기준으로 위로 늘려 그림(v4.0). 얼굴 좌표도 56칸 기준.
- 주인공 옆모습 얼굴: 눈을 얼굴 윗줄에 맞추고 피부 칸을 실제 얼굴 폭으로 줄임(v3.9). 정면·뒷모습 서 있는 칸은 두 다리 사이 1칸 틈.
- 특수 포즈(엎드림·침대에 누움·도시락)는 `tools/make_poses.py`가 걷기 도트에서 만든 임시본입니다. 누운 포즈는 같은 눈 위치에 감은 눈 선을 그리고 침대 타일의 시트·이불을 덮습니다.

- 계단: 밝은 디딤판과 검은 챌판이 번갈고, 아래(가까운 쪽)가 밝고 위로 갈수록 어두워집니다. 계단 윗칸(복도 시트 29번)은 아치형으로 뚫린 어두운 계단 통로라, 벽 안으로 이어지는 계단으로 읽힙니다. 범례에서 `S: [TH, 5, 1, 29]`.
- 침대: 머리 칸(14·15번) + 발치 칸(30·31번) 2칸짜리. 머리판 기둥·베개·접힌 시트·이불 주름·발판. 양호실은 14/30(참나무 바닥 위), 기숙사는 15/31(붉은 이불, 짙은 바닥 위). 맵에서는 `b` 아래 `f`.
- UI 창: 검은 바탕 + 가는 연보라 두 겹 선, 모서리에만 작은 금 점, 큰 창 위 가운데 붉은 마름모. 선택은 붉은 점 ● + 붉은 글자. 넘김 표시 ▼도 붉게.
- 타이틀: 「한 사람 몫의」 연보라빛 흰색, 「식탁」 붉게. 임시 타이틀 그림(cg_title)도 같은 색으로 다시 만들었습니다(검은 방, 달빛, 접시 하나뿐인 긴 식탁).

### 바닥 변형 (v1.4.1)
바닥은 한 장을 반복하지 않고 세 장(기본 + 변형 두 장)을 칸 위치에 따라 섞어 씁니다. 같은 칸은 늘 같은 타일이 나옵니다.
- 변형 타일은 기본 바닥과 이음새(널빤지 줄, 돌 줄눈 위치)를 똑같이 맞추고, 옹이·얼룩·작은 돌 정도만 다르게 그려 주세요. 눈에 띄는 무늬(금, 큰 얼룩)는 세 칸에 한 번씩 반복돼 보이니 피하는 게 좋습니다.
- 변형 번호는 아래 번호표에 굵게 표시했습니다. 변형을 그리지 않고 비워 두면 그 칸은 빈칸으로 보이니, 처음에는 기본 바닥을 복사해 넣어도 됩니다.
